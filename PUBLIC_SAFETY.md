# Public Safety

This repository is deny-by-default for sensitive information. Contributions must use synthetic data and must not contain secrets, credentials, personal information, private infrastructure, private repository references, raw diagnostic logs, real quota history, real subscription data, or local absolute paths.

The public scanner contains only generic patterns. An optional private pattern file can be supplied locally through `QUOTALOOP_PRIVATE_PATTERNS_FILE`; that file must remain untracked.

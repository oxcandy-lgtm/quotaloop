# Design System

The interface is calm, compact, and native-adjacent. Semantic tokens cover surfaces, text, borders, status colors, spacing, radius, and focus. Red is reserved for serious errors; unavailable states are neutral. Every status includes text and does not rely on color alone.

Supported layouts are desktop sidebar, tablet grid, mobile single-column content, and mobile bottom navigation. System, light, dark, reduced-motion, and visible keyboard focus are supported.

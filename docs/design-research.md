# Design Research

The interface was informed by general patterns found in public local-first tools:

- CodexBar: compact provider usage hierarchy and reset timing (MIT)
- Stats: modular menu bar information density (MIT)
- ActivityWatch: local ownership and watcher separation (MPL-2.0)

No source code, assets, icons, screenshots, or product-specific copy were copied. QuotaLoop uses its own layout, component structure, language, and visual system.
